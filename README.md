# Netflix Clone by Amit

A fully responsive Netflix-inspired web application built with modern front-end technologies. This project replicates the core UI/UX of Netflix, including authentication, movie browsing, search functionality, and dynamic data fetching.

---

## 🚀 Live Demo

🔗 [Visit Live Site](https://netflix-clone-by-amit.vercel.app/)
_(click to explore live)_

---

## ✨ Features

- 🔐 User Authentication (Login / Signup)
- 🎥 Browse Movies & others
- 🔎 Search Functionality
- 📺 Trailer Playback (YouTube integration)
- ⚡ Dynamic Data from TMDB API
- 📱 Fully Responsive Design
- 🎯 Clean and modern UI (Netflix-inspired)

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **State Management:** Context API, Redux
- **Authentication:** Firebase Auth
- **API:** TMDB (The Movie Database)
- **Deployment:** Vercel

---

## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/amitpauldev/netflix-clone.git

# Navigate to project folder
cd netflix-clone

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
```

⚠️ Never expose your API keys publicly.
